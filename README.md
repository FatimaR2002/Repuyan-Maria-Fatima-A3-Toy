Project Name: Dunkin' Layup's
How to play:
1. The game is played with a basketball and a hoop.
2. The player controls the basketball using the WASD keys on the keyboard to move up, down, left and right 
3. If the player gets the basketball into the hoop, they score a point on the tally chart. 
4. The game resets when the player reaches a score of 5 points. And the tally chart gets reset to 0.
